# Contributing to OBS Zoom and Follow Script

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear, descriptive title
- Steps to reproduce the problem
- Expected behavior vs actual behavior
- OBS version, OS, and Python version
- Any error messages from the OBS log

### Suggesting Enhancements

Enhancement suggestions are welcome! Please open an issue with:
- A clear description of the enhancement
- Why this enhancement would be useful
- Any examples or mockups if applicable

### Pull Requests

1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test your changes thoroughly in OBS
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Code Style

- Follow PEP 8 for Python code
- Add comments for complex logic
- Update documentation if adding new features
- Ensure the script still works with OBS Studio 27.0+

### Testing Checklist

Before submitting a PR, ensure:
- [ ] Script loads in OBS without errors
- [ ] All existing functionality still works
- [ ] New features are documented
- [ ] Code is commented appropriately
- [ ] No performance regressions

## Development Setup

1. Install OBS Studio
2. Install Python 3.6+
3. Clone this repository
4. Make your changes to `obs_zoom_follow.py`
5. Test in OBS via Tools > Scripts

## Questions?

Feel free to open an issue for any questions about contributing.

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on what is best for the community
- Show empathy towards other contributors

Thank you for contributing! 🎉
