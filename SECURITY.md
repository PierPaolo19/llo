# Security and Disclaimer

## ⚠️ IMPORTANT WARNINGS

This tool is provided **for educational purposes only**. By using this software, you acknowledge and agree to the following:

### Educational Purpose

- This tool is designed to demonstrate blockchain interaction concepts
- It is intended for learning about Web3 technologies and multi-chain integration
- It should NOT be used for production financial applications without proper auditing

### Read-Only Operations

This tool performs **ONLY** read operations:
- ✓ Queries blockchain data (balances, token info)
- ✓ Connects to public RPC endpoints
- ✓ Retrieves contract information
- ✗ Does NOT sign transactions
- ✗ Does NOT require private keys
- ✗ Does NOT modify blockchain state

### What This Tool Does NOT Do

1. **No Transaction Signing**: This tool cannot and will not sign or broadcast transactions
2. **No Private Key Access**: Never requires or stores private keys
3. **No Fund Manipulation**: Cannot move, transfer, or modify tokens
4. **No Wallet Creation**: Does not create or manage wallet accounts

### Security Best Practices

When using this tool:

1. **Never Share Private Keys**
   - This tool doesn't need them
   - Never enter them anywhere
   - Keep them secure and offline

2. **Verify Addresses**
   - Always double-check wallet addresses
   - Use official blockchain explorers to verify
   - Be cautious of phishing attempts

3. **Use Public Addresses Only**
   - Only query addresses you own
   - Or use publicly known addresses
   - Respect privacy of others

4. **Understand the Code**
   - Review the source code before running
   - This is open source for transparency
   - Report any security concerns
