# LLO - Learn Ledger Operations

## 🎓 Educational Blockchain Testing Tool

**FOR EDUCATIONAL PURPOSES ONLY - TESTNET USE ONLY**

This tool is designed to help developers and students learn about blockchain transactions, smart contracts, and cryptocurrency operations in a **safe, controlled environment using test networks only**.

## ⚠️ Important Disclaimers

- ✅ **TESTNET ONLY**: This tool is configured to work exclusively with test networks
- 🚫 **NO MAINNET**: Never use with real cryptocurrency or production networks
- 📚 **EDUCATIONAL**: For learning blockchain concepts and development practices
- 🔒 **NO REAL VALUE**: All tokens used are test tokens with no monetary value
- ⚖️ **LEGAL**: Only use on authorized test networks for learning purposes

## 🌐 Supported Test Networks

This tool supports the following **test networks**:

- **Ethereum Testnets**: Sepolia, Goerli (deprecated but available)
- **Binance Smart Chain Testnet**: BSC Testnet
- **Polygon Testnet**: Mumbai
- **Tron Testnet**: Shasta

## 📖 What You Can Learn

- Understanding blockchain transaction structure
- Working with test wallets and addresses
- Simulating token transfers on testnets
- Testing smart contract interactions
- Learning about gas fees and transaction costs
- Practicing secure wallet management
- Understanding blockchain explorers

## 🚀 Getting Started

### Prerequisites

- Node.js 16+ installed
- Basic understanding of blockchain concepts
- A test wallet (NEVER use real wallet keys)

### Installation

```bash
npm install
```

### Configuration

1. Create a `.env` file (never commit this file)
2. Add your **TESTNET** wallet details
3. Get test tokens from faucets (see Faucet Resources below)

### Usage

```bash
# Run the educational tool
npm start

# View examples
npm run examples
```

## 🛡️ Security Best Practices

1. **NEVER** use real private keys in testing
2. **NEVER** send real cryptocurrency to test addresses
3. **ALWAYS** verify you're on a testnet before transactions
4. **NEVER** share private keys, even for test wallets
5. **ALWAYS** use separate test wallets from real ones
