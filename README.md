# Flashing USDT Tool

A simple web-based tool for displaying USDT (Tether) cryptocurrency information with a flashing visual effect.

## Features

- Real-time USDT price display
- 24-hour price change percentage
- Market capitalization information
- Animated flashing effect (can be toggled on/off)
- Responsive design
- Auto-refresh capability

## Usage

Simply open `index.html` in your web browser. The tool will automatically fetch and display the latest USDT price information.

### Controls

- **Refresh**: Manually fetch the latest USDT data
- **Toggle Flash**: Enable or disable the flashing animation effect

## Technical Details

The tool uses:
- HTML5 for structure
- CSS3 for styling and animations
- Vanilla JavaScript for functionality
- CoinGecko API for real-time cryptocurrency data

## Local Development

1. Clone the repository
2. Open `index.html` in your web browser
3. No build process or dependencies required!
