# Flash USDT Desktop Application - Bengali Guide
# ফ্ল্যাশ USDT ডেস্কটপ অ্যাপ্লিকেশন - বাংলা গাইড

## Desktop কিভাবে ব্যবহার করবেন (How to Use Desktop)

এই গাইড আপনাকে দেখাবে কিভাবে Flash USDT Desktop অ্যাপ্লিকেশন ব্যবহার করতে হয়।

## ইনস্টলেশন (Installation)

### প্রয়োজনীয় জিনিস
- Node.js (সংস্করণ 18 বা তার বেশি)
- MetaMask বা অন্য কোন Web3 ওয়ালেট
- ইথেরিয়াম নেটওয়ার্কের সাথে সংযোগ

### ইনস্টল করুন

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/PierPaolo19/llo.git
   cd llo
   ```

2. **ডিপেন্ডেন্সি ইনস্টল করুন:**
   ```bash
   npm install
   ```

3. **Desktop অ্যাপ চালু করুন:**
   ```bash
   npm run desktop
   ```

## কিভাবে ব্যবহার করবেন (Step-by-Step Guide)

### ১. অ্যাপ্লিকেশন চালু করুন

```bash
npm run desktop
```

একটি নতুন উইন্ডো খুলবে যেখানে Flash USDT ইন্টারফেস দেখা যাবে।

### ২. ওয়ালেট সংযোগ করুন

1. উপরের ডানদিকে **"Connect Wallet"** বাটন ক্লিক করুন
2. MetaMask পপআপ আসবে - **"Connect"** ক্লিক করুন
3. আপনার ওয়ালেট ঠিকানা দেখা যাবে হেডারে

### ৩. নেটওয়ার্ক চেক করুন

**নেটওয়ার্ক স্ট্যাটাস কার্ডে** দেখতে পাবেন:
- বর্তমান নেটওয়ার্ক (Ethereum Mainnet, Sepolia, etc.)
- কন্ট্রাক্ট ঠিকানা
- পুলে উপলব্ধ লিকুইডিটি
- ফ্ল্যাশ লোন ফি

### ৪. Flash Loan চালু করুন

#### ধাপ ১: Receiver Contract Address দিন
```
আপনার ডিপ্লয় করা কন্ট্রাক্টের ঠিকানা যা IFlashLoanReceiver implement করে
উদাহরণ: 0x1234567890123456789012345678901234567890
```

#### ধাপ ২: Loan Amount লিখুন
```
কত USDT ধার নিতে চান তা লিখুন
উদাহরণ: 1000 (১০০০ USDT এর জন্য)
```

#### ধাপ ৩: Estimated Fee দেখুন
```
ফি স্বয়ংক্রিয়ভাবে হিসাব করা হবে
ডিফল্ট ফি: 0.09%
```

#### ধাপ ৪: Execute Flash Loan ক্লিক করুন
```
1. "Execute Flash Loan" বাটন ক্লিক করুন
2. MetaMask এ লেনদেন অনুমোদন করুন
3. নিশ্চিতকরণের জন্য অপেক্ষা করুন
4. Transaction History তে দেখুন
```

### ৫. Liquidity Provide করুন

**ফ্ল্যাশ লোন থেকে ফি অর্জন করতে:**

1. **"Liquidity Management"** সেকশনে যান
2. **"Provide Liquidity"** এর অধীনে:
   - USDT এর পরিমাণ লিখুন
   - **"Deposit"** ক্লিক করুন
   - USDT spending অনুমোদন করুন (প্রথমবার)
   - ডিপোজিট লেনদেন নিশ্চিত করুন

### ৬. Liquidity Withdraw করুন (শুধুমাত্র Owner)

যদি আপনি কন্ট্রাক্টের মালিক হন:

1. **"Withdraw Liquidity"** এর অধীনে:
   - উইথড্র করার পরিমাণ লিখুন
   - **"Withdraw"** ক্লিক করুন
   - লেনদেন নিশ্চিত করুন

### ৭. Transaction History দেখুন

আপনার সমস্ত ফ্ল্যাশ লোন লেনদেন দেখতে পাবেন:
- লেনদেনের ধরন এবং বিবরণ
- Transaction hash
- Block number
- ব্যবহৃত Gas

## সমস্যা সমাধান (Troubleshooting)

### "Please install MetaMask"
- MetaMask ব্রাউজার এক্সটেনশন ইনস্টল করুন
- অথবা অন্য Web3 ওয়ালেট ব্যবহার করুন

### "Contract not deployed on this network"
- MetaMask এ সমর্থিত নেটওয়ার্কে সুইচ করুন
- অথবা কনফিগারেশনে কন্ট্রাক্ট ঠিকানা আপডেট করুন

### "Transaction failed"
- গ্যাস ফি এর জন্য পর্যাপ্ত ETH আছে কিনা চেক করুন
- রিসিভার কন্ট্রাক্ট সঠিক কিনা নিশ্চিত করুন
- পুলে পর্যাপ্ত লিকুইডিটি আছে কিনা যাচাই করুন

## কিবোর্ড শর্টকাট

- `Ctrl+R`: অ্যাপ রিলোড করুন
- `Ctrl+Shift+I`: DevTools খুলুন (ডেভেলপমেন্ট মোডে)
- `Ctrl+Q`: অ্যাপ্লিকেশন বন্ধ করুন

## বিল্ড করুন (Build Executable)

আপনার নিজের কম্পিউটারের জন্য বিল্ড করতে:

```bash
# বর্তমান প্ল্যাটফর্মের জন্য
npm run desktop:build

# সব প্ল্যাটফর্মের জন্য (Windows, macOS, Linux)
npm run desktop:build-all
```

বিল্ড করা ফাইল `dist/` ডিরেক্টরিতে পাবেন।
